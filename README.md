## About Me

I’m a Computer Science student at the **University of Science and Technology Houari Boumediene (USTHB)** in Algeria. I enjoy building useful software and learning how applications are designed, developed, and maintained.

My interests include **software engineering, backend development, cybersecurity, and system design**. I’m working toward becoming an engineer who can build software that is reliable, understandable, and ready to grow.
